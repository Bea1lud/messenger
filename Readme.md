# Messenger

Веб-мессенджер на Python с сохранением истории сообщений и поддержкой скрытых сообщений.

## Возможности

* Обмен сообщениями через веб-интерфейс
* Хранение истории сообщений в JSON
* Отображение истории чата
* Клиент-серверная архитектура
* Поддержка скрытых сообщений с использованием StegCloak
* Простой интерфейс на HTML, CSS и JavaScript

## Используемые технологии

* Python
* Flask
* HTML
* CSS
* JavaScript
* JSON
* StegCloak

## Структура проекта

```text
messenger/
├── server.py
├── chat.html
├── history.json
├── requirements.txt
├── stegcloak.min.js
```

## Установка

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Запустите сервер:

```bash
python server.py
```

После запуска откройте браузер и перейдите по адресу, указанному в консоли.
